# Scriber diagnostic Sol follow-up rubric

Review each blinded A/B packet independently. Select only `A` or `B`, assess
acceptability, report every applicable binding deterministic error flag, score
each required rubric dimension from 1 to 5, and provide a concise reason.

The packet is diagnostic-only. Do not infer candidate identity, model identity,
training history, or a release decision. Do not create or use training data.
